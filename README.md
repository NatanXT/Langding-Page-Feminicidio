# Landing Page Feminicidio - Projeto Academico

Este projeto e uma landing page informativa sobre o feminicidio, desenvolvida como ferramenta de apoio para apresentacoes academicas na faculdade de Psicologia.

## Tecnologias Utilizadas

- React + Vite: Base do projeto frontend.
- Lucide React: Icones modernos e limpos.
- Framer Motion: Animacoes fluidas para uma experiencia premium.
- CSS3: Estilizacao modular e responsiva.

## Como Executar Localmente

Siga os passos abaixo para rodar o projeto em sua maquina:

1. Instale as dependencias:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
   O projeto estara disponivel em http://localhost:5173.

## Build e Deploy

Para gerar a versao de producao (para subir na Vercel, por exemplo):

1. Gere o build:
   ```bash
   npm run build
   ```

2. Deploy na Vercel:
   - Conecte seu repositorio no dashboard da Vercel.
   - O framework sera detectado automaticamente como Vite.
   - Clique em Deploy.

## Observacoes Importantes

- Verificacao de Dados: Telefones, enderecos e servicos listados devem ser conferidos em fontes oficiais antes da apresentacao final.
- Finalidade: Este e um projeto com fins estritamente educacionais e informativos.
